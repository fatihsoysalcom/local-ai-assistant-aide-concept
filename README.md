# Local AI Assistant Aide Concept

This Python script demonstrates the core concept of Aide, a local AI assistant. It simulates processing user prompts entirely on the device, ensuring data privacy by not sending information to external servers. The example uses simple keyword matching to mimic AI responses.

## Language

`python`

## How to Run

Run the script using: python aide_concept.py. Interact with the assistant by typing messages and observe its local responses.
